# D120競艇ダイス

競艇予想の出目検証に使える、無料の120面体3DダイスWebアプリです。

## 使い方
1. https://j6jz9rs79b-dot.github.io/d120-dice-/ を開きます。
2. 振るサイコロの数を選び、「まとめて振る」を押します。
3. 競艇場・レース・購入金額・買い目を入力しておくと、出目と一緒に履歴へ保存されます。
4. 履歴の「結果」と「払戻金」を入力すると、購入額・払戻額・収支を確認できます。
5. 「CSV出力」で履歴を保存できます。

## iPhoneで使う
Safariでページを開き、共有ボタンから「ホーム画面に追加」を選んでください。

## 履歴とプライバシー
履歴は利用している端末のブラウザ内に保存されます。別の端末とは自動同期されません。ブラウザのサイトデータを削除すると履歴が消える場合があります。CSV出力で定期的にバックアップしてください。

## 注意
このアプリはサイコロを振って出目を記録・検証するためのツールです。競艇の結果や的中を予測・保証するものではありません。舟券の購入はご自身の判断と責任で行ってください。
